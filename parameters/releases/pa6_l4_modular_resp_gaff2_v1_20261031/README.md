# pa6_l4_modular_resp_gaff2_v1_20261031

MD-ready modular RESP/GAFF2 parameters for zwitterionic PA6 L4 only.

Use `source leaprc.pa6_shared_p6i` in LEaP. Assemble the validated L4 sequence
as `P6N P6I P6I P6C`. The leaprc selects `mbondi3` PB radii and loads both
parameter files and all three OFF libraries.

See `manifest.json` for exact hashes, validation scope, and limitations. This
release is not evidence for arbitrary oligomer lengths or catalytic states.
