# NVIDIA collection assessment for local enzyme-design agent

**Scope:** primary model cards and NVIDIA documentation consulted 2026-11-26. The earlier search was targeted, not exhaustive; this follow-up inspects all three PI-requested collections and selected official retrieval/tool-use collections. Facts below are attributed to the linked cards/docs; recommendations are explicitly marked. No weights were downloaded and no inference was run. This is resource triage, not a scientific assessment of the Nyl12/PA6 mechanism.

## Requested collections

### BioReason-Pro 2

Collection: [BioReason-Pro 2](https://huggingface.co/collections/nvidia/bioreason-pro-2); [SFT](https://huggingface.co/nvidia/BioReason-Pro-2-9B-SFT) and [RL](https://huggingface.co/nvidia/BioReason-Pro-2-9B-RL), both 9B BF16. These produce a reasoning trace, protein-function summary, InterPro/GO terms and possible interaction partners from protein sequence/context. SFT uses 272,688 traces; RL continues SFT with GRPO. The card calls outputs research hypotheses for expert review, not verified annotations. Base lineage is Qwen3.5-9B plus frozen ESM3-open-small protein encoder, a learned projector and GO graph encoder. Governing model license is OpenMDW-1.1; component terms differ (Qwen Apache-2.0, ESM3 MIT, code MIT, training corpus CC-BY-4.0). ESM3 weights are separately downloaded. Card explicitly specifies **one 80-GB H100 minimum for inference**; SFT training used four 8×H100 nodes, RL one 8×H100 node. It outputs no sequences or structures. **Eligibility:** Qwen3.5 is the stated base. The PI explicitly directed on 26 November: do not use BioReason-Pro 2. It is excluded; no installation, download or inference is planned.

**Recommendation:** scientifically the closest of these collections for a *protein function/context* helper, but ineligible under the lineage constraint above and still a poor match to catalytic mechanism planning. It does not generate or validate protonation states, atom-mapped reaction steps, QM/MM results, TI1 geometry, or LigandMPNN mutations. Do not treat its fluent rationale as chemical evidence.

### Reasoning Efficiency Research

Collection: [Reasoning Efficiency Research](https://huggingface.co/collections/nvidia/reasoning-efficiency-research). It includes [DLER-Llama-Nemotron-8B-Merge-Research](https://huggingface.co/nvidia/DLER-Llama-Nemotron-8B-Merge-Research), [DLER-R1-1.5B-Research](https://huggingface.co/nvidia/DLER-R1-1.5B-Research), and [DLER-R1-7B-Research](https://huggingface.co/nvidia/DLER-R1-7B-Research). The first is an 8B DLER-reasoned Llama-3.1-Nemotron model, weight-merged with its base to recover accuracy; its card states research/development only and NSCLv1. The two DLER-R1 cards identify Qwen2 lineage; **exclude these under the no-Chinese-models/derivatives requirement**. The Llama model card reports about 46% shorter responses on its listed mathematical tests after DLER length-penalty training and weight merging. This is not evidence of improved Nyl12 chemistry reasoning or superiority to the deployed 120B checkpoint. These are general math/programming/scientific-reasoning LMs, not biology- or mechanism-specialized. Public cards do not establish supported memory or tested inference hardware for the GB10 Nano or the 2×96-GB workstation. Their size alone is not a hardware-feasibility result.

## Hardware answer (evidence-bounded)

No card or official documentation located establishes that any requested collection model was tested on the local 128-GB GB10 Nano or the specific 2×96-GB workstation. BioReason-Pro 2 states a one-GPU 80-GB H100 inference minimum, which is the only explicit memory floor among the candidates; it does not certify either proposed local system. ReaSyn reports A100 test hardware; KERMT's broad architecture-family list includes Blackwell but supplies no GB10 test, memory profile, or performance result. DLER cards provide no relevant local-device validation. Therefore **feasibility on either local system remains unverified**; do not infer it from aggregate/system memory or parameter count.

## Additional directly relevant NVIDIA resources

- [Nemotron 3.5 Retriever](https://huggingface.co/collections/nvidia/nemotron-35-retriever): newer embedding, reranking and document-parsing models deserve later consideration. The [3.5 Rerank 8B card](https://huggingface.co/nvidia/Nemotron-3.5-Rerank-8B-BF16) identifies a bidirectional Ministral3/Pixtral architecture and text/image document scoring. The [3.5 Embed 1B card](https://huggingface.co/nvidia/Nemotron-3.5-Embed-1B-BF16) describes text/page-image retrieval; its text tower is frozen from Nemotron-3-Embed-1B, so trace component lineage rather than assuming all similarly named models share one base. Neither is substituted into the already frozen Llama-based retrieval comparison.
- [Nemotron 3.5 Parse](https://huggingface.co/nvidia/Nemotron-3.5-Parse): C-RADIOv4 vision encoder plus mBART decoder; extracts text, layout classes, bounding boxes and reading order, including table/chart-oriented outputs. Potentially useful for problematic PDFs and figure/table evidence. It does not establish correct molecular connectivity, charges or mechanistic arrows. Keep original page images and verify extractions before using them as scientific evidence.
- [Agentic/tool-use collection](https://huggingface.co/collections/nvidia/nemotron-agentic-and-tool-use): a resource catalog, not a qualified mechanism controller. Better tool-call formatting or coding scores do not establish chemical planning reliability; typed validated adapters and project-specific tests remain necessary.
- RFD4-Proteina remains in historical inventory only. **The PI directed use of LigandMPNN rather than RFD4 for this campaign**, given the released symmetry limitation. No RFD4 pilot is queued. Boltz-2/AF3 remain existing structure-validation tools, not new mechanisms or model servers to install.

## Recommendation summary

**Recommendation, not verified result:** prioritize an ordinary, provenance-aware general reasoning agent wrapped around curated primary literature, explicit chemistry/product/protonation constraints, validated LigandMPNN variants, and deterministic QM/MM records. Among the requested collections, DLER-Llama-Nemotron is a potential efficiency-research comparison after lineage filtering, but no new language-model benchmark is justified ahead of the current retrieval test and mechanistic work. None is a demonstrated mechanism agent. Keep Nyl12/PA6 chemical interpretation and all design/QM acceptance decisions with scientific review. The model-card hardware evidence is insufficient to approve either proposed local platform for BioReason-Pro 2 or DLER inference.
